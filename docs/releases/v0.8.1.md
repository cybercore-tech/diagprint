# diagprint v0.8.1

Release date: 2026-10-02

A metadata and documentation patch. The library code and public API are
identical to v0.8.0.

## Why

The v0.8.0 packages on crates.io linked to the archived
`darkstardevx/diagprint` repository. crates.io only refreshes package metadata
on publish, so every package is republished with links to
`github.com/cybercore-tech/diagprint` and the current README.
