    04 / SAFETY MODEL
    Explain freely.
    Mutate under guard.
    
          
    Diagnostics may explain and propose. Mutation must be explicit, structured, validated, and reject uncertainty.
    
        
    
        
    
        
    
          
    Suggested shell commands are never executed. Verification is declarative, and replay never re-applies edits.
    
          
    Stale edits are rejected, not guessed. Revision-aware rendering fails closed when source identity no longer matches.
    
          
    No crash-atomic claims. Multi-file plans validate, keep recovery state and roll back observed failures, and say so plainly.

    use diagprint::{Reporter, Severity};

fn main() -> std::io::Result<()> {
    let reporter = Reporter::builder()
        .application("myapp")
        .min_severity(Severity::Info)
        .build()?;

    let diagnostic = reporter
        .error("Network initialization failed")
        .code("NET-001")
        .cause("failed to open network interface")
        .note("fallback networking is unavailable")
        .help("check interface permissions and driver state");

    reporter.emit(&diagnostic)?;
    Ok(())
}
