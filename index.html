Build the report once, then carry its meaning from a local terminal to CI, editor integrations, code scanning, and long-lived forensic history.

From noisy failure to a verified case file.

Keep the signal.

diagprint gives recurring diagnostics an identity. Compare runs, preserve privacy-aware evidence, and distinguish a new failure from the same failure wearing a new timestamp.

schema: diagprint.forensics.case-file/v1
DIAGNOSTIC CASE FILE
fingerprint: sha256:7f23a9d5c120...
status: active   chain-verified: true
